# Koi Engine 1.1.1 release notes

## Highlights

- **Search efficiency (the quiescence node diet).** Profiling showed the
  quiescence search accounts for ~98% of all visited nodes at middlegame
  depths; three measured changes cut that cost without weakening play:
  - The narrow deep quiet-check probe is disabled (≈8.5% fewer visited nodes,
    −12% time; neutral in self-play over 198 games).
  - The quiescence futility margin is tightened 306 → 200 centipawns
    (≈20% fewer visited nodes, −18% time; **+3.5%** score in the self-play A/B
    over 198 games).
  - Metadata construction is skipped for discarded quiet moves at
    check-generating quiescence nodes (tree-identical, ≈1% time).
  Net effect: the depth counter climbs noticeably faster at long think times.
- **Analysis UX.** With `Threads>1` and `MultiPV>1`, interim `info` lines now
  report the live in-flight leader's principal variation on the first line
  while the remaining ranks republish the last completed lines.
- **Docs.** New [Lichess bot starter](../lichess-bot.md) and
  [Apple Silicon worker setup](../mac-worker.md) pages.

## Compatibility

- UCI options, defaults, and the optional-asset behavior are unchanged from
  1.1.0 (`Hash=512`, `Threads=1`, `OwnBook=false`, `EvalFile` optional).
- `Threads=1` remains deterministic; `Threads>1` results are intentionally
  nondeterministic.
- No book, tablebase, or network data ships with the engine.

## Verification

- Full CTest suites on Linux, Windows, and macOS CI; the Mac release
  verification harness (Debug + Release builds, UCI smoke, replay, threading
  and timing checks); self-play A/B runs for each search change.
- Measurement provenance: classical evaluator, Apple M4, `Threads=1`, the
  depth-6 probe corpus; the ledger records the full profile.
