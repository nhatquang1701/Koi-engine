# Koi Engine v1.1.3

## Highlights

- **Official NNUE network ships with the release.** The new `v7` network
  (`koi-v7-official-20261021.nnue`) is trained on a 30M-position corpus and is
  gated on both axes before shipping:
  - **+70.4 Elo** vs the classical evaluator at equal nodes (300 games,
    score 0.6000);
  - **+106.3 Elo** at equal time (1+0, 64 games, score 0.6484).
  The network is opt-in: set `EvalFile` to the shipped file (or enable it in
  your GUI). The classical evaluator remains the default and the fallback.
- **UCI shutdown hardening.** `quit` during a search no longer emits a late
  `info` line; search output is suppressed as soon as shutdown begins.
- **NNUE inference speed.** The bottleneck dot product in the network forward
  pass is vectorized; measured at parity-to-positive on the reference Mac.
- **Tooling.** New SPSA search-parameter tuner (`tools/measurement/spsa_search.py`)
  with a macOS variant runner, a v1 halfka-only dataset writer for the v4
  trainer, and an optional network payload in the release packaging
  (`nnue/koi.nnue` + SHA-256 sidecar + metadata, recorded in `package.json`).
- **Documentation.** New architecture and NNUE-pipeline pages, both rendered
  from Mermaid diagrams.

## Compatibility

- UCI options are unchanged from 1.1.2. `EvalFile` stays optional; an empty
  value keeps the boot-time evaluator.
- `Threads=1` remains deterministic; `Threads>1` uses Lazy SMP and is
  intentionally nondeterministic.
- No book or tablebase data is bundled.

## Verification

- Full CI matrix green (Linux, Windows, macOS, documentation).
- Release-net rule: the shipped network is never weaker than the classical
  evaluator at equal time; the timed gate above is the evidence.
- All speed and strength claims come from the pinned Stockfish 19 reference
  and the fixed match harness with distinct-game validation.
