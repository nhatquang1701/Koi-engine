# Koi Engine v1.0.0 release notes

This is the first public release candidate of Koi Engine's classical CPU UCI
engine for Windows x64 and Linux x86-64. Publication depends on the release
evidence report and its gates passing for the exact archive hashes.

## Install

Download the archive and its matching `.sha256` file. Verify the SHA-256, then
extract the archive. Add `koi-engine.exe` on Windows or `koi-engine` on Linux
to a UCI chess GUI. The launcher selects the fastest bundled CPU build that
the host supports and retains a baseline x86-64 fallback. The Linux package
is built against Ubuntu 22.04 (glibc 2.35); it has not been certified on older
glibc versions.

Each archive includes the README, `INSTALL.txt`, the project MIT license,
third-party licenses, and `package.json` with per-file hashes and source
provenance. Check that `provenance.source_dirty` is `false` for a release
candidate archive.

## Configuration

The default path uses the classical CPU evaluator. Start with `Threads=1`,
`Hash=512`, and `Speed=100`; increase Threads if the host has spare cores.
`OwnBook=true` is the default, but no `book.bin` is distributed. Add a
licensed book beside the executable or set `OwnBook=false`. NNUE, GPU NNUE,
and Syzygy tablebases are optional and require user supplied assets or
hardware as described in the README.

Koi does not advertise `UCI_LimitStrength` or `UCI_Elo` in v1.0.0. The former
node limit did not provide a calibrated Elo value. `StrengthMode` and `Speed`
remain available, but should not be interpreted as rating promises.

## Current limits

The search suite documents outstanding move-choice expectations as `XFAIL`
and a small number of timing-sensitive expectations as intermittent; see
`tests/README.md`. The release evidence report records the exact tested
binaries, test outcomes, game counts, and strength bound. No numerical Elo
rating is claimed by these release notes.
